# Recipe — créer un ticket (→ `000-backlog`)

1. Copier [`../../../workflow/TEMPLATE.md`](../../../workflow/TEMPLATE.md) dans
   `project/000-backlog/` sous le nom **`YYYY-MM-DD_HH-MM_titre.md`** (heure de
   création ; `titre` court en kebab-case).
2. Renseigner le frontmatter (`id`, `title`, `type`, `created`) et l'**Objectif**.
3. C'est tout — la tâche attend d'être priorisée puis spécifiée
   ([ticket-specify](ticket-specify.md)).
