## Objectif

Rendre la page de démo du moteur (`src/engine/demo/`) plus **soignée et agréable**
— présentation, lisibilité, aide aux contrôles. Aujourd'hui c'est un showcase
fonctionnel mais brut (titre + sous-titre + viewport). Viser une **finition
visuelle « produit »**, **mobile-first**, sans toucher au moteur.

## Contexte / liens

- `src/engine/demo/index.html`, `src/engine/demo/demo.css`, `src/engine/demo/demo.js`
- **Contrainte** : ne **pas** modifier le moteur (`src/engine/` hors `demo/`) ni la
  frontière — la démo consomme le moteur via `src/engine/index.js`.
- Recipe utile : `meta/recipes/verify-in-browser.md` (piège rAF, `?debug=1`).

## Definition of Done

- [x] En-tête / mise en page plus soignée (typographie, espacements, cohérence
      visuelle — thème sombre assumé possible).
- [x] **Aide aux contrôles** visible (flèches pour marcher ; mention de `?debug=1`).
- [x] **Responsive / mobile-first** : lisible et jouable sur petit écran
      (idéalement des contrôles tactiles ; sinon au moins une mise en page adaptée).
- [x] **Aucune régression** : la démo tourne, 0 erreur console, moteur intact.

## Vérification

- [x] `npm run verify` vert
- [x] validation navigateur (desktop **et** petit écran) — voir
      `meta/recipes/verify-in-browser.md`
